# A&P RAG

A retrieval-augmented generation system for undergraduate anatomy and physiology, focused on cardiovascular physiology as an initial domain.

## What this is

An open-source research project building and evaluating a RAG system over undergraduate anatomy and physiology learning materials, with a focus on identifying where naive retrieval fails for biology pedagogy and which advanced techniques address those failures.

## Why

Most current RAG evaluation uses general-purpose proxy metrics that don't reflect how students actually learn or misunderstand biological concepts. This project develops a domain-specific evaluation framework grounded in real pedagogical failure modes and tests whether techniques like hybrid retrieval, reranking, and graph-augmented retrieval improve performance on the dimensions that matter for science education.

## Status

Early development. Repository scaffolded, baseline RAG pipeline in progress, evaluation set under construction. Initial scope is cardiovascular physiology using OpenStax Anatomy and Physiology as the primary corpus.
